## North-Star Objective

Build an open-world 3D voxel MMORPG that fuses **Xianxia Four-Path Immortal Cultivation**, **trillion-scale (`1,000T`) castle warfare**, **Avatar / Clone / Shadow tactical combat**, and **deterministic procedural WebGL2 graphics** inside a fail-closed, auditable full-stack TypeScript & C++20 architecture.

## Strategic Pillars

1. **Unbounded Precision**: Replace lossy IEEE-754 floats with native `BigInt` across troop counts, realm suppression (`100.0x`), and Googl-scale lore addressing (`10^97` volumes / `10^100` words).
2. **Zero External Asset Bloat**: Synthesize 100% of terrain geometry, PBR surface maps (`CanvasTexture`), species traits, and Web Audio waveforms procedurally in-engine.
3. **Server-Authoritative Fairness**: Enforce `20Hz` (`50ms`) siege ticks, HMAC-SHA256 sessions, Firebase ID verification on `/api/db/*`, zero-trust `firestore.rules`, and `AuthoritativeAntiCheatEngine`.
4. **Cross-Device Parity**: Run smoothly across Dedicated Desktop GPUs (`BC7 4K`), Apple Silicon UMA, Mobile Touch (`ASTC`), and Headless SwiftShader WebGL2.
