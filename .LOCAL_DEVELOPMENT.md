# Local Development Quickstart (`.LOCAL_DEVELOPMENT.md`)

Local workstation setup, dual-persistence wiring (SQL/Firestore + JSON), WebSocket `/ws/siege` testing, and troubleshooting guide for **Voxel Realms RPG: Open World MMORPG & Castle Warfare (`v1.5.0`)**.

---

## 1. Prerequisites

| Tool                                            | Minimum Version                                    | Purpose                                                       |
| :---------------------------------------------- | :------------------------------------------------- | :------------------------------------------------------------ |
| **Node.js**                                     | `>= 20.0.0` (LTS `22.x` recommended)               | Express server (`server.ts`), Vite 8, `tsx --test` runner     |
| **npm**                                         | `>= 10.0.0`                                        | Package management & script orchestration                     |
| **Git**                                         | `>= 2.40`                                          | Version control & pre-commit hook execution                   |
| **CMake + Ninja + C++20 Compiler** _(Optional)_ | CMake `>= 3.24`, GCC 12+ / Clang 16+ / MSVC 19.34+ | Native `cpp/VoxelRealmsGuardrails.hpp` & `ctest` verification |
| **PostgreSQL 15+** _(Optional)_                 | Local Postgres or Cloud SQL Proxy                  | Required only when testing `/api/db/*` Drizzle routes         |

## 2. First-Run Boot Sequence

1. **Install dependencies:**

   ```bash
   npm install
   ```

2. **Copy environment template & set mandatory secrets:**

   ```bash
   cp .env.example .env
   ```

   Populate `VOXEL_SESSION_SECRET` (`>= 16` chars in dev, `>= 32` chars in production) and `VOXEL_ADMIN_PASSKEY` (`>= 12` chars) in `.env` (replace the `.env.example` placeholders). Example generator:

   ```bash
   node -e "console.log('VOXEL_SESSION_SECRET=' + require('crypto').randomBytes(32).toString('hex'))"
   ```

3. **Start the unified full-stack development server on port `3000`:**

   ```bash
   npm run dev
   ```

   This runs `tsx server.ts`, mounting:
   - HTTP/Express API (`/healthz`, `/readyz`, `/api/auth/*`, `/api/online/*`, `/api/admin/*`, `/api/db/*`)
   - RFC 6455 WebSocket Siege server (`/ws/siege`)
   - Vite development middleware (`vite.middlewares`) serving the React 19 + Three.js client at `http://localhost:3000`.

4. **Skip the Title Screen automatically during rapid UI iteration:**

   ```text
   http://localhost:3000/?autostart=1
   ```

## 3. Environment Modes & Fail-Closed Guardrails

- **Mandatory Secrets Across All Modes (`development` & `production`)**:
  - `server.ts` / `serverAuth.ts` **never generate ephemeral default secrets**. Both `VOXEL_SESSION_SECRET` and `VOXEL_ADMIN_PASSKEY` must be explicitly configured and must not match `.env.example` placeholders, or the server logs `[SECURITY FATAL]` and exits immediately (`process.exit(1)`).
- **Development Mode (`NODE_ENV !== 'production'`)**:
  - Requires `VOXEL_SESSION_SECRET` (`>= 16` chars) and `VOXEL_ADMIN_PASSKEY` (`>= 12` chars).
  - Cloud SQL `pg.Pool` (`src/db/index.ts`) initializes **lazily** on `/api/db/*` requests; missing `SQL_HOST` will not block `/healthz` or offline gameplay.
- **Production Mode (`NODE_ENV=production`)**:
  - Server **fails closed** on startup (`process.exit(1)`) unless `VOXEL_SESSION_SECRET` (`>= 32` chars) and `VOXEL_ADMIN_PASSKEY` (`>= 12` chars) are explicitly set to non-placeholder values (`environment hardening.md`).

## 4. Essential Local Verification Loop

```bash
npm run lint          # Strict TypeScript check (tsc --noEmit)
npm run lint:rules    # ESLint audit of firestore.rules
npm run format:check  # Prettier style compliance
npm test              # 168 unit, MIME, security, netcode & rules tests (28 suites)
npm run verify:ops    # Live production server load, exploit & crash-recovery probe
npm run validate      # Complete 5-stage gate (lint + lint:rules + format:check + test + build)
```

## 5. Troubleshooting Common Local Issues

- **Port `3000` already in use**: Terminate stale node/tsx listeners (`lsof -ti:3000 | xargs kill -9`) and re-run `npm run dev`.
- **WebGL running on CPU SwiftShader**: Expected inside headless Chromium containers; `GameCanvas.tsx` + `architectOptimization.ts` automatically downgrade post-processing (`UnrealBloomPass`) and cap DPR to `1.0` so UI frames stay responsive.
- **Playwright or HMR WebSocket errors**: `DISABLE_HMR='true'` disables Vite HMR intentionally inside sandboxed preview frames; WebSocket errors are isolated to `/ws/siege` during offline mode and fall back cleanly to local prediction.
